# NotesHub

Учебный проект, разработанный в рамках внутреннего образовательного трека компании **TechNotes**.

Проект представляет собой простой веб-сервис для хранения личных заметок пользователей.

Основная цель проекта — реализовать базовый функционал управления заметками (CRUD) и получить первый опыт командной разработки.

---

## Технологический стек

### Frontend

- React
- TypeScript
- Vite

### Backend

- Node.js
- Express
- TypeScript

---

## Структура проекта

```
notes-hub/
│
├── frontend/     # Клиентское приложение
├── backend/      # REST API
└── docs/         # Документация проекта
```

---

## Возможности

Текущая версия приложения позволяет:

- просматривать список заметок;
- создавать заметки;
- редактировать заметки;
- удалять заметки.

---

## Запуск проекта

### Backend

```bash
cd backend
npm install
npm run dev
```

Сервер будет доступен по адресу

```
http://localhost:3000
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение будет доступно по адресу

```
http://localhost:5173
```

---

## Структура данных

Каждая заметка содержит:

| Поле | Тип |
|------|-----|
| id | number |
| title | string |
| content | string |
| authorId | number |
| createdAt | string |

## Ограничения текущей версии

В рамках MVP не реализованы:

- регистрация пользователей;
- полноценная авторизация;
- поиск заметок;
- категории;
- прикрепление файлов;
- совместный доступ.
